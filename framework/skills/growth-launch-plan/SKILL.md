# Launch Plan

## Prerequisites

Run `scripts/validate.sh` first. Requires: PRD exists.

## Instructions

1. Read `docs/teams/product/PRD.md` — understand target user and value proposition
2. Read `docs/teams/growth/TEAM_BRIEF.md` if it exists
3. Build the launch plan using `templates/LAUNCH_PLAN.md`:

### Planning Process

a. **Define launch goals** — what does success look like on day 1, week 1, month 1?
b. **Identify channels** — rank by effort vs. expected impact:
   - Organic: SEO, content marketing, community, social
   - Paid: ads, sponsorships, influencers
   - Direct: email, personal outreach, Product Hunt, HN
c. **Pre-launch checklist** — what must be ready before launch
d. **Launch day sequence** — hour-by-hour plan
e. **Post-launch** — first week activities, feedback loops, iteration plan
f. **Metrics** — define launch success metrics with targets

4. Write to `docs/teams/growth/LAUNCH_PLAN.md`
5. Present to user for review

## Rules

- Focus on high-leverage, low-cost channels first (solo-founder constraint).
- Every recommendation includes effort estimate vs. expected impact.
- Be specific: "Post on HN at 8am EST Tuesday" not "consider social media."
