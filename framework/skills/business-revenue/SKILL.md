# Revenue Model

## Instructions

1. Read `docs/teams/product/PRD.md` — understand features and target market
2. Read `docs/teams/business/TEAM_BRIEF.md` if it exists
3. Build the revenue model using `templates/REVENUE_MODEL.md`:

### Modeling Process

a. **Choose revenue model type:**
   - SaaS subscription (monthly/annual)
   - Usage-based / pay-per-use
   - Freemium with premium tiers
   - Marketplace (transaction fee)
   - One-time purchase
   - Present options with trade-offs if unclear

b. **Competitive pricing research:**
   - Use WebSearch to find 3-5 direct competitors' pricing pages
   - Document in a comparison table: competitor, tiers, prices, key features per tier
   - Identify the pricing gap or positioning opportunity

c. **Design pricing tiers** (if applicable):
   - Base pricing on competitive data and value delivered
   - Define features per tier
   - Price points with competitive justification
   - Free tier scope (if freemium) — generous enough to hook, limited enough to convert

c. **Calculate unit economics:**
   - CAC (Customer Acquisition Cost)
   - LTV (Lifetime Value)
   - LTV:CAC ratio (target > 3:1)
   - Payback period

d. **Build 3 scenarios:** Conservative, Base, Optimistic
   - 12-month projections minimum
   - State every assumption explicitly

4. Write to `docs/teams/business/REVENUE_MODEL.md`
5. Present to user for review

## Rules

- Every number has an assumption: `ASSUMPTION: [X]`
- Show calculation methodology. No black-box projections.
- Use conservative defaults unless directed otherwise.
- Base pricing on competitive data and value delivered, not cost.
